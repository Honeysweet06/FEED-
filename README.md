# 🍽️ FEED: Food Emergency Assistance & Distribution System

A mobile-responsive web-based system designed to support efficient food aid distribution, monitoring, and coordination between government agencies and communities.

---

## 📌 Project Overview

The **FEED System** is a prototype platform that helps manage and visualize food assistance operations. It includes dashboards, mapping features, role-based workflows, and administrative tools to improve transparency and response during emergencies.

This project is developed as part of a **BSIT Capstone Project**.

---

## ✨ Key Features

- 📊 **Dashboard Overview**
  - Real-time metrics and status tracking
  - Barangay-level distribution updates

- 🗺️ **Interactive Map**
  - Visual representation of food distribution areas
  - Status indicators (urgent, low supply, stable)

- 👥 **Roles & Workflow**
  - Role-based system (Admin, Staff, Volunteers)
  - Clear task delegation and coordination

- 🏢 **Admin Panel (CSWD)**
  - KPI monitoring
  - Inventory tracking
  - Reports and analytics

- 💬 **Messaging & Alerts (UI Prototype)**
  - Communication interface for coordination
  - Notification system for urgent needs

---

## 🛠️ Technologies Used

- HTML5  
- CSS3 (Responsive Design)  
- JavaScript (UI interactions)  
- Leaflet.js (Map integration)  
- Google Fonts (Inter)

---

## 📱 System Type

- ✅ Frontend Prototype  
- ❌ Backend Integration (Not yet implemented)

> Note: This system is currently a **static demo UI**. Backend integration (e.g., Firebase or Supabase) is planned for future development.
